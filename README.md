# Reactor
A simple reaction time game/measuring tool built in AutoHotkey V1.

<img width="1920" height="1039" alt="image" src="https://github.com/user-attachments/assets/3e458ce1-6622-402b-a1e7-57bca143598b" />

## Instructions
Choose the number of pop-ups (randomly appearing buttons you must click as fast as possible), their size (defaults to the "Click To Start" button's size), and the time range between which pop-ups appear (default: one pop-up every 500ms to 1500ms). After that, click the start button, and click the pop-ups (labeled "Click Me") as fast as you can. After every pop-up is clicked, a message box will appear stating your results. Enjoy!
